# ChatGPT Keyboard — ранний прототип

## Сборка APK через GitHub Actions (можно с телефона)

1. Создай репозиторий на GitHub и загрузи в него содержимое этой папки.
2. Открой вкладку **Actions** в репозитории.
3. Запусти workflow **Build Android APK** через **Run workflow** (или дождись сборки после push).
4. Открой завершённый запуск workflow, найди **Artifacts** и скачай `ChatGPTKeyboard-debug`.
5. Распакуй архив артефакта и установи `app-debug.apk` на телефон.

## Включение на Huawei

1. Открой приложение ChatGPT Keyboard.
2. Нажми «Открыть настройки клавиатур».
3. Включи ChatGPT Keyboard в списке методов ввода.
4. В любом поле ввода выбери её через переключатель клавиатуры.

## Важно

Это ранний демонстрационный прототип. В нём есть базовый ввод и переключение трёх раскладок с эмодзи.
Переводчик, автокоррекция, полноценные языковые словари и подключение ИИ ещё не реализованы.
Не вводи пароли и другую конфиденциальную информацию в тестовую клавиатуру.
